Como corrigir a autenticação

Gere um novo Access Token na Clicksign Sandbox, associe seu e-mail à API e substitua a variável CLICKSIGN_ACCESS_TOKEN na Vercel, somente no Preview. Faça um novo deployment após salvar.

Nunca cole a credencial no chat. O envio continuará bloqueado até a API aceitar o novo token.
